 ##### SHRUTI MATH TOOL

 This is a menu driven console project made by using c++ .
 It can perform different mathematical calculations, number analysis and unit conversion.

 # Main Menu

 - Basic Calculations
 - Number Analysis
 - Conversion
 - Exit

 ### Features 

 # Basic Calculations
 - Addition
 - Subtraction
 - Multiplication
 - Divivsion
 - Modulus
 - Power
 - Square root
 - Percentage
 - Absolute Value

 # Number Analysis

 - Even/Odd
 - Factorial
 - Prime Number Check
 - Factor of Number
 - GCD
 - LCM
 - Palindrome Check
 - Fibonacci Series
 - Digit Sum
 - Reverse Number

# Conversion

- Temperature 
- Length
- Weight
- Time
